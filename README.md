# Student Management System

**Technology Used:** HTML, CSS, JavaScript, Tailwind CSS (via CDN)
**Features Implemented:**
- Dashboard with total count, department-wise, and year-wise summaries.
- Student List with Add, Edit, Delete capabilities.
- Local Storage integration to persist data without a backend.
- Search by name or register number.
- Filter by department.
- Sort by name and register number.
- Responsive design for Mobile, Tablet, and Desktop.

## How to Run the Application
1. Extract the downloaded ZIP file.
2. Open `index.html` in any modern web browser (e.g., Chrome, Edge, Firefox).
3. No server or build process is required!
